# Lodestone Coordinates

A tiny client-side Fabric mod that shows the dimension, coordinates, and distance a lodestone compass points to — right in the item tooltip.

## Features

- **Dimension** — which dimension the compass is bound to (Overworld, The Nether, The End, or any modded dimension)
- **Coordinates** — the exact X, Y, Z of the bound lodestone
- **Distance** — how far away the lodestone is, in blocks (same dimension only)
- **Cross-dimension awareness** — clearly marks when the lodestone is in another dimension
- **Unbound detection** — identifies compasses that have never been bound

## How to use

Bind a compass to a lodestone, then hover over the compass. The tooltip shows everything. No config, no commands.

## Supported versions

All stable releases from **1.21 to 26.2** (1.21 – 1.21.11, 26.1, 26.1.1, 26.1.2, 26.2). Each version has its own jar in Releases.

## Requirements

- Fabric Loader 0.16+
- Fabric API
- Java 21 (1.21.x) or Java 25 (26.x)

## Compatibility

Client-side only — works on vanilla and modded servers with nothing server-side required.
